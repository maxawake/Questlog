# Questlog
Adventurous todo list app

- [`questlog/`](questlog) – the self-hosted web app and Python/FastAPI CalDAV
  adapter that syncs with Nextcloud. See [questlog/README.md](questlog/README.md).
- [`quests/`](quests) – the Expo (React Native) Android/iOS app with the same
  features, connecting to a `questlog` server. See [quests/README.md](quests/README.md).
